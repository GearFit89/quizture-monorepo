# Dev Log: 2026-11-24

## Recall page

- Added a Recall page (`/recall`, optional `?count=N`, default 10) to apps/expo-app. `RecallQuiz` takes an array of `QuizQuestion`s and resolves each question/answer by ID from the question data.
- Answers are built from word blocks: every word of the answer plus 4-6 random distractor words drawn from the quiz's question texts (words already in the answer are excluded). Blocks are shuffled; answers are checked in order, ignoring case and punctuation.
- Correct answers get a green answer area, a scale "pop", and a "Correct!" card; incorrect answers get a red shake and a card showing the correct answer. A review screen at the end shows the score, each question, the user's answer, and the correct answer for misses, with a "Try again" button.
- New files: src/app/recall.tsx, src/components/recall/*, src/hooks/recall.hook.ts, src/lib/recall/recall.ts, test/recall.test.ts.
- Changed files (per AGENTS.md): lib/content/content.json (`recall` group), lib/content/types.ts (`RecallContent`), lib/styles/content.ts (`recall` group, typed with `satisfies StyleClass` so React Native literal style types are preserved).
- Decisions: the hook and content selector live in a new recall.hook.ts and are imported directly instead of editing hooks/index.ts, to avoid changing existing files. Native hex colors were used because theme.colors holds Tailwind expressions.

## Recall review fixes

- Task: fixed two Devin Review findings on the Recall page.
- `?count=` now falls back to the default length (10) unless it is a positive integer (`parseRecallCount`), so `-1` or `0.5` no longer give a full-bank or empty quiz.
- `pickDistractors` now tops up from the whole question bank when the quiz's own questions have too few eligible words, so short quizzes still get 4–6 distractors.
